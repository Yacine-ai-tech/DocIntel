# Self-Hosting DocIntel

1. **Environment:** Copy `.env.example` to `.env` and configure your database and standard generic endpoints (e.g., Vision URL, LLM endpoint).
2. **Docker:** Deploy using `docker-compose.yml`.
3. **GPU Note:** If running Surya or Marker natively, a CUDA GPU with 16GB+ VRAM is recommended.
4. **Hosting:** Render free tier or a dedicated on-demand GPU cloud host.
